# 观澜量化 · A股/美股策略回测与实时监控

一套小型量化交易系统：**回测 → 报告 → 实时监控 → 模拟盘**，全程只用免费公开行情数据，不动真钱。

## 四个交付物

| 交付物 | 位置 | 给谁用 |
|---|---|---|
| Windows 程序 | `dist/guanlan-quant.exe`（旁边放 `config.json`） | 双击就能跑回测、看监控 |
| Excel 报表 | `output/回测报告_*.xlsx` | 指标总览 / 资金曲线 / 逐笔交易 / 说明 |
| PDF 研报 | `output/量化策略研报_*.pdf` | 策略详情 + 收益曲线图 + 风险提示 |
| 在线监控台 | https://eason724.github.io/quant-watch/ | **自选决策台**（客户自己加自选股、调参数、看四策略实时信号与迷你回测）+ 官方模拟盘 + 回测报告，实时行情每 30 秒自动刷新 |

## 自选决策台（在线版核心功能）

- 客户输入代码添加自选（A股 6 位 / 美股字母，自动识别市场），保存在自己设备浏览器里；
- 每个自选标的显示实时价格和四种策略的当前信号（仓位状态 + 依据）；
- 参数页面上直接改（均线周期、RSI 阈值、网格步长/格数），点"重算"立即生效；
- 每个策略附近 3 年迷你回测净值曲线——计算全部在浏览器本地完成，数据来自东财公开接口。

## Windows 程序

把 `dist/guanlan-quant.exe` 和 `config.json` 放在同一个文件夹，双击运行：

- `[1]` 一键回测 → 在 exe 旁边生成 `output/回测报告_*.xlsx` + `量化策略研报_*.pdf`
- `[2]/[3]` 实时监控 + 模拟盘记账
- `[4]` 重置模拟盘

数据缓存在 exe 旁的 `data_cache/`，模拟盘账本在 `output/paper_account.json`。

## 四种策略（新手版解释）

1. **双均线趋势**：短期均线（10日）升破长期均线（30日）→ 趋势走强，买入；跌破 → 卖出。吃趋势行情，震荡市会小亏多次。
2. **动量轮动**：每隔一段时间，把资金挪到"最近 20 天涨得最猛"的 ETF 上（本配置四选一）；全部走弱就空仓。2022 年以来跑得最好，但换手高。
3. **均值回归（RSI）**：RSI 跌破 30（超卖）买入博反弹，涨到 70（超买）卖出。低频，信号少。
4. **网格交易**：以起始价为中心，每跌 3% 补一格仓位、每涨 3% 卖一格，越跌越买、越涨越卖。适合震荡市，单边下跌会持续加仓。

## 交易与费用口径

- **T 日收盘算信号，T+1 开盘价成交**（含滑点），不偷看未来。
- A股/ETF：整手（100股）取整，佣金万 0.5（免印花税），滑点万 5；美股：1 股粒度，佣金 0，滑点万 2。
- 权重变动 < 0.5% 不交易（省手续费）；停牌日不交易。
- 指标：年化按 252 交易日折算；夏普比率无风险利率取 0；胜率=盈利卖出笔占比。

## 配置

所有标的、参数、费率都在 `config.json`：改股票代码（A股 6 位、美股如 SPY/QQQ）、调均线周期、换 ETF 池，改完重跑即可。

## 能力边界（诚实版）

**工具能保证的**：数据真实（东财公开行情）、不偷看未来（T 日收盘信号 → T+1 开盘成交）、费用与滑点计入、
A股 T+1 与一字涨跌停约束已建模、停牌不交易、现金流逐笔可核验（`self_test.py` 14 项测试全部通过）。

**工具做不到的**：预测政策、识别坐庄与内幕、躲过基本面地雷。自测里的真实样本——均值回归策略踩雷乐视网
（407 天停牌 + 复牌连续跌停 + 退市），实测最大回撤 **-97.3%**，任何规则都救不了这种雷。
任何声称程序能预测这些的，都是骗局。

**定位**：纪律执行器 + 策略研究工具。它最大的价值是用规则代替情绪——A股散户亏钱的主因是追涨杀跌，
纪律本身是稀缺品。但这**不等于盈利保证**：回测 +178.6% 的动量轮动，换个参数窗口可能就是另一番结果。

## 风险提示

回测基于历史数据，存在过拟合风险，**不代表未来收益**。实盘还会遇到流动性不足、涨跌停无法成交、数据延迟等回测未覆盖的问题。本工具仅用于策略研究，不构成投资建议。
